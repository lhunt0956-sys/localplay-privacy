# 个股分析 & 交易策略模块

## 适用场景
- "XX股票值得买吗"
- "我要不要加仓/减仓"
- "现在是买入时机吗"
- "这支股票跌了好多，要不要补仓"
- 仓位管理、止盈止损相关问题

---

## 分析框架：三层递进法

### 第一层：宏观背景（市场环境对不对）
先判断大环境，顺势而为：
- 当前牛市/熊市/震荡市？
- 政策面是收紧还是宽松？
- 利率环境（影响资金成本和估值）

### 第二层：基本面分析（公司本身好不好）
适合 Hunt 现在持有的银行、能源、电力类股票：

**关键指标**（必须附括号解释）：
- `PE（市盈率，股价÷每股收益，反映贵不贵，银行/能源股一般5-10倍算合理）`
- `PB（市净率，股价÷每股净资产，银行股看PB更重要，低于1倍通常被低估）`
- `股息率（每年分红÷股价，高于4%通常认为有防御价值）`
- `ROE（净资产收益率，公司用自有资金赚钱的能力，持续高于15%是优质公司信号）`
- `营收/净利润增速（同比增长还是下滑？）`

**查询方式**：搜索 `[股票名] 基本面 最新财报 PE PB`

### 第三层：技术面参考（短期买入时机）
新手不建议过度依赖技术面，但以下几个简单指标可以参考：

| 指标 | 含义 | 简单用法 |
|------|------|---------|
| MA均线（移动平均线） | 一段时间的平均股价 | 股价站上MA60日线，趋势偏多 |
| RSI（相对强弱指数） | 超买超卖判断 | 低于30可能超卖，高于70可能超买 |
| 成交量 | 市场参与热度 | 放量上涨比缩量上涨更可信 |

## 买卖决策检查清单

在给出买/卖/持有建议前，逐项检查：

**买入前问**：
- [ ] 公司基本面是否支撑当前价格？（PE/PB是否合理）
- [ ] 是否有明确的买入逻辑（不是因为别人说买）？
- [ ] 买入后仓位比例是否合理（单只股票建议不超过总仓位30%）？
- [ ] 能承受多少亏损而不影响生活？

**卖出/减仓前问**：
- [ ] 是止损（跌到设定的亏损线）还是止盈（达到目标收益）？
- [ ] 卖出逻辑是否清晰，还是只是情绪恐慌？
- [ ] 是否在低点因恐慌卖出（这是最常见亏损原因）？

## 仓位管理原则（新手版）

适合 Hunt 当前阶段的简单仓位原则：

```
总资金分配建议：
├── 核心仓（60-70%）：防御型高股息股（神华、长电、工行）
│   特点：波动小、有股息、适合长拿
├── 卫星仓（20-30%）：成长性标的（半导体ETF等）
│   特点：波动大、长期逻辑好、不要频繁操作
└── 现金（10-20%）：保留机动资金
    特点：下跌时可以加仓，不要满仓
```

## 常见陷阱警告

每次策略分析，根据情境选一条插入：

- **追涨杀跌**：股票涨了很多再买、跌了很多就卖——是散户最常见亏损模式
- **频繁操作**：A股交易有手续费+印花税，频繁买卖会侵蚀收益
- **消息炒作**：听到"内部消息"要买某股，99%是陷阱
- **补仓陷阱**：一支股票一直跌一直补，可能越补越亏（先判断逻辑是否变化）
- **满仓操作**：永远留一部分现金，机会来了才有子弹
