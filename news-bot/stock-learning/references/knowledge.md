# 新手知识成长路径地图

## 适用场景
- "什么是XX"类概念问题
- "我怎么学股票"
- "帮我解释一下XX指标"
- "为什么市场会这样反应"

---

## Hunt 的知识成长路径（分阶段）

### 🌱 阶段一：市场基础认知（当前阶段）

目标：搞清楚"股市是什么、怎么运作的"

| 知识点 | 核心问题 | 优先级 |
|--------|---------|--------|
| A股市场结构 | 上交所/深交所/北交所有什么区别 | ⭐⭐⭐ |
| 股票是什么 | 买股票=买公司一小部分 | ⭐⭐⭐ |
| 指数是什么 | 沪深300/上证50/创业板指的含义 | ⭐⭐⭐ |
| 交易规则 | T+1、涨跌停板、手续费 | ⭐⭐⭐ |
| ETF是什么 | 和股票有什么区别，为什么适合新手 | ⭐⭐⭐ |
| 财报基础 | 营收、净利润、现金流怎么看 | ⭐⭐ |
| PE/PB/股息率 | 最基础的估值工具 | ⭐⭐ |

### 🌿 阶段二：价值投资入门（3-6个月后）

目标：能独立分析一家公司是否值得买

| 知识点 | 核心问题 |
|--------|---------|
| 护城河理论 | 什么样的公司有持久竞争优势 |
| DCF估值法 | 用未来现金流估算公司内在价值 |
| 行业分析框架 | 如何判断一个行业的天花板和竞争格局 |
| ROE拆解（杜邦分析） | 公司靠什么赚钱（提效率/加杠杆/提利润率） |
| 格雷厄姆防御型投资原则 | 安全边际的概念 |

### 🌳 阶段三：宏观 & 技术综合（6-12个月后）

目标：能判断市场环境，做出动态调整

| 知识点 | 核心问题 |
|--------|---------|
| 货币政策 | 降息/降准如何影响股市 |
| 经济周期 | 复苏/过热/滞胀/衰退 四阶段资产配置 |
| 技术分析基础 | 趋势线、支撑阻力、形态识别 |
| 资产配置理论 | 股债平衡、再平衡策略 |
| 行为金融学 | 为什么人类总在错误时间做错误决策 |

## 概念解释模板

当 Hunt 问"什么是XX"时，按以下结构回答：

```
**[概念名]**（[英文/缩写]）

【一句话定义】：用最简单的话说清楚是什么

【生活类比】：用日常场景类比，帮助理解

【在股市中的用法】：投资者怎么用这个概念做判断

【局限性】：这个指标/概念有什么不适用的地方

【Hunt 的案例】：结合他的持仓举一个具体例子
```

## 推荐学习资源（A股友好）

**书籍（由浅到深）**：
1. 《股市真规则》— 帕特·多尔西（行业分析入门，非常实用）
2. 《聪明的投资者》— 本杰明·格雷厄姆（价值投资圣经，读第8和20章）
3. 《彼得·林奇的成功投资》— 选股思维，适合散户

**中文资源**：
- 集思录（可转债、ETF数据，数据质量高）
- 东方财富Choice数据（财报、估值查询）
- 雪球（看别人的分析思路，但要独立判断）

**避免**：财经抖音/直播荐股、股票群"内部消息"

## 知识点之间的关联图（文字版）

```
宏观经济（利率/政策）
    ↓ 影响
行业景气度（哪个行业在受益）
    ↓ 影响
公司基本面（营收/利润变化）
    ↓ 反映在
股票估值（PE/PB是否合理）
    ↓ 配合
技术面时机（何时买入）
    ↓ 管理好
仓位与风险（不满仓、有止损）
```

每次 Hunt 学到一个新概念，告诉他它在这个链条的哪个位置，帮助他建立整体认知地图。
